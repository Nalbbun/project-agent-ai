📈 SFT → GRPO 학습 파이프라인

역할 준수와 포맷 안정화를 먼저 확보하고, 이후 자동 평가 가능한 역할부터 GRPO를 적용합니다.

Phase 1

SFT 선행

PM, Architect, Dev 중심으로 역할과 형식을 먼저 고정합니다.

Phase 2

Offline Eval

schema pass, task pass, role-specific metrics를 측정합니다.

Phase 3

GRPO

Dev와 QA처럼 자동 평가가 쉬운 역할부터 보상 기반 최적화를 적용합니다.

Phase 4

Orchestration & Production

Router, RAG, Runner, Approval, Observability를 포함한 운영형 배포 단계입니다.
